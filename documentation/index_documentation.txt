STOCKDO ERP - DOCUMENTATION MASTER INDEX
================================================================================

This file serves as the master navigation index for all documentation generated for the StockDo ERP project. It categorizes the text files by module and functional domain. 
Each entry contains the file name and a brief explanation of what is contained within the file.

--------------------------------------------------------------------------------
1. MASTER DATA & CRM
--------------------------------------------------------------------------------
These modules define the core entities of the system, including who you do business with and what you track.

- company_details_documentation.txt: Documentation of the global settings and root identity provider module.
- company_settings_exhaustive_details.txt: Architectural breakdown of the Singleton pattern and backend logic for company settings.
- customers_documentation.txt: Documentation for the Customers CRM, tracking client details and interactions.
- customers_exhaustive_details.txt: Database schema and architectural details for Customer entities.
- suppliers_documentation.txt: Documentation for the Suppliers CRM, tracking vendors and supply chain partners.
- suppliers_exhaustive_details.txt: Database schema and architectural details for Supplier entities.
- employees_documentation.txt: Documentation for the Employees CRM, tracking staff details and HR metrics.
- employees_revenue_exhaustive_details.txt: Architectural breakdown linking employees to revenue generation and roles.
- materials_documentation.txt: Documentation for the Materials module, defining products, parts, and inventory items.
- materials_exhaustive_details.txt: Architectural details on material properties, HSN codes, and inventory metrics.
- vehicles_documentation.txt: Documentation for the Vehicles module, tracking fleet details and compliance.
- vehicles_exhaustive_details.txt: Architectural details for fleet tracking and compliance deadline management.
